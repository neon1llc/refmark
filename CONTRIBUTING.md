# Contributing

Issues and pull requests are welcome.

```sh
npm ci
npm test
node bin/refmark.mjs --help
```

- Node.js 20 or later, one runtime dependency. Open an issue before adding another.
- Every file opens with a comment saying what it's for. Non-obvious rules get a short comment saying why.
- Tests use Node's built-in runner and a local HTTP server, with no internet access.
- Use [Conventional Commits](https://www.conventionalcommits.org/) on a `feat/`, `fix/`, `docs/`, or `chore/` branch.
- Add a line to `CHANGELOG.md` for any change users would notice.
- Releases follow neon1's [release levels](https://github.com/neon1llc/neon1-corpus/blob/main/corpus/standards/versioning.md#release-levels): Implemented, Verified, Released, and Qualified. A tag marks Released. Qualified means the weekly check has run on real repositories for a month without false alarms.

`watch/neon1.json` is generated by `refmark scan` from neon1's repositories. To change it, edit the citing document there. If a source needs a scope or rule, open an issue here.
