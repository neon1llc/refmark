# Contributing

Thanks for helping. Issues and pull requests are welcome.

## Working on the code

```sh
npm ci
npm test
node bin/refmark.mjs --help
```

- Refmark runs on Node.js 20 and later and keeps to one runtime dependency. Please discuss a new dependency in an issue first.
- Every file opens with a comment saying what it is for, and each section, export, and non-obvious rule gets a short comment explaining why.
- Tests use Node's built-in test runner and a local HTTP server. They never reach the internet.
- Commits follow [Conventional Commits](https://www.conventionalcommits.org/), such as `feat(scan): read AsciiDoc links`, on a `feat/`, `fix/`, `docs/`, or `chore/` branch.
- Add a line to `CHANGELOG.md` under "Unreleased" for anything a user would notice.

## Adding to neon1's watch list

`watch/neon1.json` is generated by `refmark scan` from neon1's repositories. To change what it watches, change the citing document in its own repository, or open an issue here if a source needs a scope or a rule.
